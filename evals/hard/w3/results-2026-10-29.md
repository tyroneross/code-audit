# W3 results, 2026-10-29: frozen values and brittle paths

The pre-registered claim failed: the W3 guidance did not outperform the no-guidance control or either source on review. Under the pre-registered oracle it scored worse than all four comparators (2/12 against 4–5/12 on the primary set). That loss came entirely from an oracle omission. With the oracle corrected from the fix commits, the W3 arm ties the earlier Code Audit bundle and both sources (4/12 each), and the control is one trial ahead (5/12, parity). One post-hoc iteration of the guidance then detected 8/12. That is 0.25 above the control and 0.33 above each source, but the iteration was written after seeing these cases, so it is not independent evidence.

## Why the pre-registered result was "worse"

W02's fix commit (1d476a1) removed two hard-coded maintainer paths: one in `scripts/assumption_register.py` and one in `skills/silent-assumptions/SKILL.md`. The oracle named only the first. Both W3 repetitions reported the second copy and not the first, so they scored as misses. The corrected oracle extends every window to all lines the fix commit changed in the packet files; only W02 gained new findings, and a fresh blinded judge re-graded its packet. This correction was made after the scores were seen. Both results are reported here.

## What W3 measured

A bundle carries only the four SKILL.md files. The W3 arm therefore measured one routing line and one inline paragraph. Checklist sections F and G and the frozen-values procedure are referenced but not included, so they were not measured. The iteration changed only that paragraph and the routing line, adding "confirm by comparing each version, path, id, name table and copied list with its source in every supplied file".

## Limits

- **Post-hoc fixes.** The oracle correction and the iteration were both made after the subject's scores were seen. The iteration targets the case shapes it then caught, so its gain may not transfer. It needs a fresh case set.
- **Confound.** The same agent mined the cases and wrote the guidance in one session.
- **Sample size.** Six primary cases with two repetitions each. One trial is 0.083.
- **Judging.** Three blinded Opus-tier judges, each finding judged once. Two-part defects count one part as a match.
- **Unmeasured.** Claude-hosted arms were not run: no API key, and the Keychain is off-limits.
